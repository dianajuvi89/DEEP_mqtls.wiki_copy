We have a preference that you impute your genetic data with one the imputation server. However if you can't impute your dataset using an external server and you need help with imputation please contact [Prachand Issarapu](mailto:Prachand.Issarapu@lshtm.ac.uk). 

Please note there are several imputation servers:
- [UK imputation service] (https://imputation.sanger.ac.uk/) (hosted at Sanger, Hinxton, UK): . You can impute with the following [panels] (https://imputation.sanger.ac.uk/?about=1#referencepanels): 1000Genomes Phase 3, African Genome Resources, Haplotype Reference Consortium  
- European imputation service (hosted in Munich, Germany): [https://imputationserver.helmholtz-munich.de/](https://imputationserver.helmholtz-munich.de/). You can impute with 1000Genomes phase3 and Haplotype Reference Consortium
- US imputation service (hosted at Michigan, USA). You can impute with the following [panels](https://genepi.github.io/michigan-imputationserver/getting-started/#reference-panels): 1000 Genomes Phase 3, CAAPA - African American Panel, Genome Asia Pilot, Human Reference Consortium
