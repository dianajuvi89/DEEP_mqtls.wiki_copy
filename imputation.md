We have a preference that you impute your genetic data with one the imputation server. However if you can't impute your dataset using an external dataset and you need help with imputation please contact Prachand Issarapu . 

Please note there is a new European imputation service (hosted in Munich, Germany) where you can impute using HRC: [https://imputationserver.helmholtz-munich.de/](https://imputationserver.helmholtz-munich.de/)

This is still an online server, but if you can only share/upload genotype data within the EU, this might be a good option.
